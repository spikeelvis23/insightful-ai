# FREQUENCY (The Frequency — Spiral Media)

- AI-powered hip-hop media curation tool, built under the Spiral Media brand
- Shares a design system with DIASPORA: deep black backgrounds, gold accents, Playfair Display / Space Mono typography
- Involves Anthropic API integration, AI agent architectures, editorial workflow tooling — including journalist dashboards with role-based access control

Since this shares infrastructure and design language with DIASPORA, an agent building either
one should read `diaspora.md` too before starting.
